# SEO: семантическое ядро и структура сайта

## Файлы

| Файл | Что внутри |
|---|---|
| `semantic-core.csv` | ~2 500 запросов: запрос · тип · кластер · целевая страница · приоритет · пустая колонка для частоты. Открывается в Excel (UTF-8, разделитель `;`). |
| `stats.json` | Сводка: сколько запросов какого типа и на сколько страниц. |

Ядро генерируется скриптом `npm run seo` из тех же данных, что и страницы сайта
(`src/data/*.ts`). Добавили услугу, марку или статью — перегенерируйте ядро, и новые
запросы сразу окажутся привязаны к реальным URL.

> Частоты из Яндекс Wordstat в облачной среде получить нельзя, поэтому колонка
> «Частота» пустая. Приоритеты A/B/C расставлены экспертно. Следующий шаг —
> прогнать ядро через Wordstat (или Key Collector / Rush Analytics) с регионом
> «Чебоксары» и удалить нулевые запросы.

## Типы запросов

- **Коммерческие** — «покраска бампера цена», «кузовной ремонт чебоксары», «покраска kia rio».
  Ведут на страницы услуг, марок и моделей, где есть цены и калькулятор.
- **Информационные** — «как убрать царапину на машине», «где найти код краски».
  Ведут на статьи `/stati/…`, из которых человек переходит в калькулятор.
- **Локальные/навигационные** — «кузовной ремонт водопроводная», «кузовной сервис рядом».
  Ведут на `/kontakty/` и главную; усиливаются карточками в Яндекс Бизнесе и 2ГИС.

## Структура сайта (кластер → страница)

| Раздел | URL | Кластеры |
|---|---|---|
| Главная | `/` | кузовной ремонт и покраска + Чебоксары |
| Калькулятор | `/kalkulyator/` | «калькулятор покраски авто», «рассчитать стоимость кузовного ремонта» |
| Услуги (17) | `/uslugi/<услуга>/` | покраска, локальная/полная покраска, бамперы, PDR, рихтовка, ДТП, стапель, пороги и арки, антикор, полировка, керамика, плёнка, диски, подбор краски |
| Цены | `/ceny/` | «цены на кузовной ремонт», «покраска двери/капота/крыла цена» |
| Марки (46) | `/marki/<марка>/` | «кузовной ремонт kia», «покраска тойота» |
| Модели (96) | `/marki/<марка>/<модель>/` | «покраска kia rio», «покраска бампера солярис» |
| Статьи (9) | `/stati/<статья>/` | информационные запросы |
| Вопросы | `/voprosy/` | вопросы о ценах, сроках, гарантии |
| Работы | `/raboty/` | «до и после», примеры работ |
| Контакты | `/kontakty/` | локальные запросы, адрес |

Каждая страница получает уникальные `title`, `description`, `h1`, `canonical`,
Open Graph и микроразметку Schema.org (`AutoBodyShop`, `Service`, `Offer`,
`FAQPage`, `BreadcrumbList`, `Article`). Страницы пререндерятся в статический HTML —
поисковики видят полный текст без выполнения JavaScript.

## Что сделать после запуска

1. **Яндекс Вебмастер** и **Google Search Console**: подтвердить сайт, отправить `sitemap.xml`.
2. **Яндекс Бизнес** и **2ГИС**: карточка организации с адресом, телефоном, фото работ,
   ссылкой на сайт. Для локальной выдачи это важнее всего остального.
3. **Яндекс Метрика**: указать номер счётчика в `src/config.ts` (`metrikaId`) — цели уже
   отправляются: `calc_start`, `calc_add`, `calc_order`, `order_pdf`, `order_tg`,
   `order_max`, `order_ig`, `lead_calculator`, `call`, `messenger`.
4. **Отзывы**: просить клиентов оставлять отзывы на Яндекс Картах и в 2ГИС.
5. **Фото работ**: добавить реальные «до/после» (см. `src/data/works.ts`) — это
   повышает конверсию и даёт трафик из поиска по картинкам.
6. **Контент**: раз в 2–4 недели добавлять статью под информационный кластер из ядра.
