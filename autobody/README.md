# Сайт кузовного центра — Чебоксары, ул. Водопроводная, 2А

Кузовной ремонт и покраска авто: онлайн-калькулятор со схемой кузова, заказ-наряд
(PDF / печать / копирование / Telegram / MAX / Instagram / заявка), SEO-страницы
услуг, марок и моделей, статьи, FAQ, контакты с картой.

Стек: React 18 + TypeScript + Vite + Tailwind CSS 4. Все страницы пререндерятся
в статический HTML (для индексации Яндексом и Google), затем «оживают» в браузере.

## Команды

```bash
npm install
npm run dev        # разработка: http://localhost:3000
npm run build      # сборка в dist/: 178 HTML-страниц + sitemap.xml + robots.txt + 404.html
npm run preview    # просмотр собранного сайта
npm run seo        # пересобрать семантическое ядро в seo/semantic-core.csv
```

## Публикация

Загрузите содержимое `dist/` на любой хостинг с PHP (Beget, Timeweb, REG.RU…).
`.htaccess` уже настроен (https, слэши, 404, кэш). Для nginx: `try_files $uri $uri/ =404;`
и `error_page 404 /404.html;`.

Заявки с сайта принимает `dist/send.php` — укажите в нём e-mail и/или токен
Telegram-бота. Пока ничего не указано, заявки пишутся в файл `leads.log` уровнем
выше корня сайта.

## Где что менять

| Что | Файл |
|---|---|
| Название, телефон, почта, Telegram, MAX, часы работы, домен, Метрика | `src/config.ts` |
| Цены, коэффициенты классов, скидки за объём, доп. услуги | `src/data/pricing.ts` |
| Марки и модели (класс, SEO-страница, «слабые места») | `src/data/cars.ts` |
| Тексты услуг, цены «от», FAQ услуг | `src/data/services.ts` |
| Статьи | `src/data/articles.ts` |
| Общий FAQ | `src/data/faq.ts` |
| Фото работ «до/после» | `src/data/works.ts` + `public/works/` |
| Готовые сценарии калькулятора | `src/data/scenarios.ts` |

## Что нужно подтвердить у заказчика (сейчас стоят заглушки)

- Название компании (`SITE.name`) и домен (`SITE.url`)
- E-mail, Telegram, MAX — кнопки сами включатся, когда контакты появятся в конфиге
- Часы работы, срок гарантии, индекс
- Цены и скидки за объём (3 эл. — 5%, 6 — 10%, 10 — 15%) — рассчитаны как ориентир по рынку
- Оборудование и технологии, упомянутые в текстах: покрасочная камера, спектрофотометр,
  стапель, PDR, пайка пластика, способы оплаты
- Реквизиты оператора персональных данных на странице `/politika/`
- Фото работ из Instagram (из облачной среды Instagram недоступен)
